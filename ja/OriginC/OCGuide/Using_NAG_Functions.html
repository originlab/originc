ヘッダファイルNAGヘッダファイル

NAG関数を呼び出すには、NAG関数が宣言されているヘッダファイルを含める必要があります。

一般的に使用されるすべてのNAGヘッダファイルを含む単一のヘッダファイルを以下に示します。通常、このヘッダファイルをコードに含めるだけで問題ありません。 

#include <OC_nag.h> // 全てに共通のNAGヘッダファイル

単一のNAG関数または少数のNAG関数のみを使用する場合は、独自のNAGヘッダファイルを含めることもできます。例えば、コード内でNAG関数c06gzcが呼び出された場合、関連する2つのNAGヘッダファイルを含める必要があります。 

#include <NAG\nag.h>    // NAG 構造体と型の定義
#include <NAG\nagc06.h> // c06 関数の宣言も含む

エラー構造NAGエラー構造

全てのNAG関数は、NagError構造体のポインタである引数を1つだけ受け取ります。この構造体は、NAG関数が正常に実行されているかどうかをテストするために使用されます。

以下の例では、NAG関数c06gzcが正常に動作するかどうかを示します。 

NagError err;                    // エラー構造体を宣言
c06gzc(n, v, &err);              // NAG c06gzc 関数を呼び出し
if( err.code != NE_NOERROR )     // エラーが発生した場合
    printf(err.message);         // エラーメッセージを出力

呼び出しが成功したかどうかを知る必要がない場合は、エラー構造体の宣言は不要です。そして、代わりにNAGERR_DEFAULTマクロを渡すことができます。このマクロはNULLポインタです。将来のバージョンのNAG関数との互換性を確保するために、エラー構造なしで作業できる場合は、このマクロを使用することをお勧めします。 

c06gzc(n, v, NAGERR_DEFAULT);

コールバック関数NAGコールバック関数

NAGライブラリでは、ほとんどのルーチンにコールバック関数が含まれています。コールバック関数を定義する前に、NAGがコールするときに期待するコールバック関数の戻り型と引数型を知っておく必要があります。

NAG関数d01ajcを例にとります。ヘッダファイルnagd01.hでは、最初の引数がNAG_D01AJC_FUN fであることが分かります。この引数はコールバック関数です。次に、nag_types.hで、NAG_D01AJC_FUNがNAG_D01_FUNの型であることが判明しました。これは次のように定義されます。 

typedef double (NAG_CALL * NAG_D01_FUN)(double);

次に、コールバック関数を次のように定義します。 

double NAG_CALL myFunc(double x)
{
    double result;
    // 'x'で処理
    return result;
}

NAG関数d01ajcを呼び出すとき、 myFunc（上で定義）を最初の引数として渡すことができます。

c05adcの呼び出しの例

この例では、NAG関数c05adcを呼び出す方法を示します。4番目の引数はコールバック関数の引数です。NAG_C05ADC_FUN型のコールバック関数はnag_types.hで定義されています。 

typedef double (NAG_CALL * NAG_C05ADC_FUN)(double);

定義から、戻り値型と唯一の引数型の両方がdoubleであることがわかっています。コールバック関数を次のように定義します。 

double NAG_CALL myC05ADCfunc(double x)
{
    return exp(-x)-x;
}

myC05ADCfuncコールバック関数を渡してc05adc関数を呼び出す方法を以下に示します。 

double a = 0.0, b = 1.0, x, ftol = 0.0, xtol = 1e-05;
NagError err;

c05adc(a, b, &x, myC05ADCfunc, xtol, ftol, &err);

NAGがOriginからデータを取得

多くのNAG関数は数値データの配列へのポインタを取ります。Originワークシートと行列シートはどちらもデータへのポインタを取得できます。このポインタはNAG関数に渡すことができます。Origin Cでは、データは一般にDatasetまたはDataRangeオブジェクトを使用して渡されます。以下のセクションでは、DatasetとDataRangeを使用してワークシートからデータを渡す方法を示します。DataRangeの使用を推奨します。

Dataset

Datasetオブジェクトは、そのDatasetがNAG関数によって期待されるデータ型である限り、NAG関数に渡すことができます。Originワークシート列のデータ型は、既定で文字と数値です。全てではありませんが、ほとんどのNAG関数では、NAG関数は浮動ポインタや整数ポインタを期待するため、このデータ型を渡すことはできません。

DatasetがNAG関数によって期待される型であることを確認する場合は、次のコードを使用してDatasetオブジェクトをNAG関数に渡すことができます。 

//アクティブなワークシートへのアクセス
Worksheet wks = Project.ActiveLayer();

// データセットを構築し、wksデータにアクセス
Dataset dsX, dsY;
dsX.Attach(wks, 0);
dsY.Attach(wks, 1);

// NAGの nag_1d_spline_interpolant(e01bac)関数を呼び出し
NagError err;
Nag_Spline spline;
e01bac(m, dsX, dsY, &spline, &err);

データ範囲

DataRangeクラスは、ワークシートの列が文字と数値型であっても、ワークシートからベクトルにデータを取得するためのGetDataメソッドを提供します。GetDataメソッドは欠損値を持つ行を簡単に無視することもできますが、これはNAG関数にデータを渡すときに非常に重要です。

NAG, Memory Free DataRangeを使用してOriginからNAG関数にデータを渡す方がはるかに安全であり、推奨されます。次の例はその方法を示しています。 

void call_NAG_example()
{
	int i, numPoints = 5;

	// 新しいワークシートページを作成
	WorksheetPage pg;
	pg.Create("origin");

	// アクティブワークシートにアクセスして2列追加
	Worksheet wks = Project.ActiveLayer();
	//  X2列追加
	i = wks.AddCol();
	Column col(wks, i);
	col.SetType(OKDATAOBJ_DESIGNATION_X);
	//Y2列追加
	wks.AddCol();

	// 最初の2列でいくつかの開始XY値を作成
	Dataset dsX, dsY;
	dsX.Attach(wks, 0);
	dsY.Attach(wks, 1);
	for (i = 0; i < numPoints; i++)
	{
		int r = rnd(0) * 10;
		if (r < 1)
			r = 1;
		if (i > 0)
			r += dsX[i - 1];
		dsX.Add(r);
		dsY.Add(rnd(0));
	}

	// データ範囲オブジェクトを作成
	DataRange dr;
	dr.Add(wks, 0, "X");
	dr.Add(wks, 1, "Y");

	// データ範囲を使用してwks からデータをvedtorにコピー
	//このコピーは値が欠損している行を無視
	vector vX1, vY1;
	dr.GetData(DRR_GET_DEPENDENT, 0, NULL, NULL, &vY1, &vX1);

	// NAGを呼び出して係数を計算
	NagError err;
	Nag_Spline spline;
	e01bac(vX1.GetSize(), vX1, vY1, &spline, &err);

	// スプラインの XY 値を取得
	vector vX2, vY2;
	double fit, xarg;
	for (i = 0; i < vX1.GetSize(); i++)
	{
		vX2.Add(vX1[i]);
		vY2.Add(vY1[i]);
		if (i < vX1.GetSize() - 1)
		{
			xarg = (vX1[i] + vX1[i + 1]) * 0.5;
			e02bbc(xarg, &fit, &spline, &err);
			vX2.Add(xarg);
			vY2.Add(fit);
		}
	}

	// NAGで割り当てられたメモリを解放
	NAG_FREE(spline.lamda);
	NAG_FREE(spline.c);

	// ワークシートにスプライン値をコピー
	dsX.Attach(wks, 2);
	dsX = vX2;

	dsY.Attach(wks, 3);
	dsY = vY2;
}

NAG e04関数を呼び出す方法

以下の例では、NAG関数nag_opt_simplex_easyを安全に呼び出す方法を示します。そして結果はファイルに出力されます。 

#include <OC_nag.h>

#define NULLFN NULL

void text_e04cbc()
{
        double objf;
	double x[2];
	Integer maxcal, n;
        NagError fail; 

	printf("\ne04cbc example: \n");

        maxcal = 100;
	n = 2;
	x[0] = 0.4;
	x[1] = -0.8;
        tolf = sqrt(nag_machine_precision);
	tolx = sqrt(tolf);
	try
	{
		// NAG関数usn e04cbc = nag_opt_simplex_easyを呼び出し
		nag_opt_simplex_easy(n, x, &objf, tolf, tolx, funct, NULLFN, maxcal, NAGCOMM_NULL, &fail);  
	}
	catch(int err)
	{
		printf("\nerror = %d\n", err);  //例外がある場合
	}
	printf("fail->code = %d\n", fail.code);  // エラーコード
	printf("fail->message = %s\n", fail.message);  // エラーメッセージ

        printf("The final function value is %12.4f\n", objf);
	printf("at the point");
	for (int ii = 1; ii <= n; ++ii)
	{
		printf(" %12.4f", x[ii-1]);
	}
	printf("\n");
}

//nag_opt_simplex_easyのコールバック関数
void NAG_CALL funct(Integer n, double* xc, double* objf, Nag_Comm* comm)
{
	*objf = exp(xc[0])*(xc[0]*4.0*(xc[0]+xc[1])+xc[1]*2.0*(xc[1]+1.0)+1.0);
}
