事前定義クラスOrigin定義クラス

Origin Cには、Originデータ型とユーザインターフェイスオブジェクトを操作するための事前定義されたクラスが含まれています。これらのクラスは、一般的なタスクを達成するためのOrigin Cコードを素早く書くのに役立ちます。このセクションでは基本クラスを紹介し、その機能の概要を説明します。Origin定義クラスの詳細と例については、次の章の事前定義クラスまたはOrigin C Wikiを参照してください。

クラス、ユーザ定義ユーザ定義クラス

Origin Cはユーザ定義クラスをサポートしています。ユーザ定義クラスを使用すると、メソッド(メンバ関数)とデータメンバを使用して独自の型のオブジェクトを作成できます。

以下の例では、Bookクラスを次のように定義しています。

  • 作成時に名前を設定するコンストラクタ
  • const getter (constオブジェクトを呼び出しても安全)
  • 2つのsetterオーバーロード(C-stringまたはstringから)。
class Book
{
public:
    // コンストラクタ
    Book() : m_strName("") {}                  // デフォルト
    Book(LPCSTR name) : m_strName(name) {}     // 作成時に名前を設定

    // Getter（const Bookに対しても呼び出せるようconstにする）
    string GetName() const
    {
        return m_strName;
    }

    // Setters（利便性のためにオーバーロード）
    void SetName(LPCSTR lpcszName)
    {
        m_strName = lpcszName;
    }
    void SetName(const string& name)
    {
        m_strName = name;
    }

private:
    string m_strName;
};

次に、Bookオブジェクトを宣言し、その名前を設定して出力する簡単な使用例を示します。 

void test_class()
{
    Book one;                    // デフォルトのコンストラクタ
    one.SetName("ABC");
    out_str(one.GetName());

    const Book two("Origin C");  // 名前を指定して構築；constオブジェクト
    out_str(two.GetName());      // OK (GetName がconst)
    // two.SetName("new");       // 許可しない: 'two' は const
}

クラス、継承継承

__super

オーバーライドする関数の基本クラス実装を呼び出します。 

class base
{
public:
    virtual void fun(){ out_str("Base"); }
};
class A :public base
{
public:
    void fun(){ out_str("A");}
};
class B :public A
{
public:
    void fun()
    {
        __super::fun();//  A::fun()を呼び出す
        out_str("B");
    }
};
void main()
{
    B b;
    b.fun();
}
